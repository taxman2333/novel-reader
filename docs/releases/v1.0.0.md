一个只服务于个人的本地 TXT 小说阅读器。**完全本地运行**：不接入服务器、账号或云同步，不上传小说文件或阅读数据。

## 下载与使用

下载下方的 `novel-reader-1.0.0-win-x64.zip`，解压后双击 `书页之间.exe`。

**不需要安装 Node.js。** 这是免安装版：不写注册表、不装进 `Program Files`，卸载就是删掉解压出来的文件夹。仅提供 Windows x64 版。

## 这个版本包含

- 导入本地 `.txt`，只记录原文件路径与元数据，**不复制小说正文**
- 自动识别编码（UTF-8 / UTF-8 BOM / UTF-16LE / GB18030）
- 书架：书名、上次阅读时间、阅读进度；原路径失效时支持重新定位
- 阅读器：工具栏固定于顶部、正文区独立滚动、底部细进度条
- 阅读进度自动保存与恢复
- 阅读设置：字号、行距、段落间距、版心宽度、字体、段首缩进；**按书记忆**
- 四种主题：日间白色、日间暖色（默认）、日间护眼浅绿色、夜间深灰
- **章节目录**：自动识别章节并可点击跳转；识别不到章节时降级为按百分比跳转
- 删除书架记录**不会**删除电脑上的原始小说文件

完整说明见仓库中的 `README.md`，逐项变更见 `docs/CHANGELOG.md`。

## 需要知道的两件事

**一、书架数据不随这个压缩包移动。** 它保存在 `%APPDATA%\local-novel-reader\`。

**二、书架记录保存的是小说文件的绝对路径。** 把应用拷到另一台电脑后，即使一并复制了书架数据，路径对不上也无法打开原书。这是「小说正文不复制到应用内部、只记录原文件路径」这一设计的必然结果，不是缺陷。

## 已知限制

- 没有自定义应用图标，沿用 Electron 默认图标
- 仅打包 Windows x64；无安装程序、无自动更新
- 数十 MB 的超长篇 TXT 会把全部段落一次性渲染为 DOM 节点，未做分块或虚拟滚动

# 书页之间

一个只服务于个人的本地 TXT 小说阅读器。应用使用 Electron 运行，界面使用 Vite、原生 JavaScript 和 CSS 构建。

## 当前功能

- 从系统文件选择器导入本地 `.txt` 文件。
- 只保存原始文件路径和书籍元数据，不复制小说正文；仅为恢复阅读位置保存约 240 字的「附近文本」。
- 根据保存的路径重新读取小说。
- 自动保存和恢复阅读位置。
- 自动识别章节并生成目录，点击目录跳转到该章开头；识别不到章节时降级为按百分比跳转。
- 记录文件变化并在原路径失效时支持重新定位。
- 调整字号、行距、段距、版心宽度、字体和段首缩进。
- 提供日间白色、日间暖色、日间浅绿色和夜间深灰四种主题。
- 删除书架记录时不会删除电脑中的原始文件。

## 使用打包好的应用

从 Releases 下载 `novel-reader-<版本>-win-x64.zip`，解压后双击 `书页之间.exe` 即可，**不需要安装 Node.js**。

书架数据保存在 Electron 的用户数据目录（Windows 下为 `%APPDATA%\local-novel-reader\`），不随压缩包移动。另需注意：**书架记录保存的是小说文件的绝对路径**，把应用拷到另一台电脑后，即使一并复制了书架数据，路径对不上也无法打开原书。

## 开发环境

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

运行测试：

```bash
npm test          # 单元测试
npm run test:ui   # 界面回归测试（构建 + 真实 Electron 窗口）
```

生成前端生产构建：

```bash
npm run build
```

打包为 Windows 免安装应用（产物在 `release/`，需要联网下载 Electron 运行时）：

```bash
npm run dist
```

本应用完全本地运行：不接入服务器、账号或云同步，不上传小说文件或阅读数据。书架数据保存在 Electron 的用户数据目录中，小说正文始终保留在用户原来的文件位置——应用内只保存路径、元数据，以及恢复阅读位置所必需的约 240 字「附近文本」，不保存正文副本。

## 说明

普通浏览器页面不能可靠地在下次启动时直接读取任意本地路径，因此本项目必须通过 Electron 桌面窗口运行。直接在浏览器中打开 `src/index.html` 只能看到不具备本地文件访问能力的提示页。

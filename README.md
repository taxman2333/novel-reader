# 书页之间

一个只服务于个人的本地 TXT 小说阅读器。应用使用 Electron 运行，界面使用 Vite、原生 JavaScript 和 CSS 构建。

## 当前功能

- 从系统文件选择器导入本地 `.txt` 文件。
- 只保存原始文件路径和书籍元数据，不复制小说正文。
- 根据保存的路径重新读取小说。
- 自动保存和恢复阅读位置。
- 记录文件变化并在原路径失效时支持重新定位。
- 调整字号、行距、段距、版心宽度、字体和段首缩进。
- 提供日间白色、日间暖色、日间浅绿色和夜间深灰四种主题。
- 删除书架记录时不会删除电脑中的原始文件。

## 开发环境

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

运行测试：

```bash
npm test
```

生成前端生产构建：

```bash
npm run build
```

当前版本没有配置远程仓库，也不会上传小说文件或阅读数据。书架数据保存在 Electron 的用户数据目录中，小说正文始终保留在用户原来的文件位置。

## 说明

普通浏览器页面不能可靠地在下次启动时直接读取任意本地路径，因此本项目必须通过 Electron 桌面窗口运行。直接在浏览器中打开 `src/index.html` 只能看到不具备本地文件访问能力的提示页。
